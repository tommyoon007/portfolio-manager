추천 비중 엔진 설명
추천 비중 엔진 v4
성장성 25% + 수익성 20% + 재무건전성 20% + FCF 10% + 밸류에이션 15% + 위험도 10%를 이용해 종목별 점수를 계산합니다.

성장성: 매출 성장률 + 이익 성장률
수익성: 영업이익률 + ROE
재무건전성: 부채비율 + 유동비율 + 영업현금흐름 + 순부채/EBITDA + 이자보상배율
밸류에이션: PEG + PER + PSR + EV/EBITDA
FCF: FCF 마진 + FCF Yield
위험도: Beta + 순부채/EBITDA + 이자보상배율 + 희석차이

자산유형 보정: ETF·채권 ETF는 개별기업 펀더멘털 대신 ETF 역할·분산·집중도 기반 별도 점수를 사용합니다. 개별주식은 기존 100점 펀더멘털 모델을 적용하며, 성장주·가치주·혼합형 스타일은 표시용으로 분류합니다.

데이터가 없는 항목은 해당 항목의 중립점수를 사용합니다. 따라서 특정 데이터가 없다고 해서 해당 종목 전체가 자동으로 불리해지지는 않습니다.

추천비중은 종목당 최대 30%로 제한합니다. 상한 때문에 100%를 채울 수 없는 경우 남은 비중은 현금·미배분으로 남깁니다.

추천비중 적용을 누르면 추천비중이 목표비중으로 복사되고, 추가매수/매도 금액 계산에 바로 반영됩니다.
